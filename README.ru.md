qview — быстрый и простой просмотрщик изображений для Windows. Изображение открывается за доли секунды, остальные изображения папки листаются без задержек, а окна настроек нет: немногочисленные параметры находятся в меню.

![qview показывает фотографию с открытым контекстным меню; сверху меню и панель инструментов, внизу строка состояния](images/screenshot.png)

*Снимок экрана версии 0.2.0; на панели инструментов текущей версии больше кнопок.*

## Возможности

- Запуск до появления изображения занимает около 0,2 с: декодирование начинается ещё до создания окна и выполняется в фоновых потоках.
- Мгновенное листание: соседние изображения декодируются заранее.
- Изображения упорядочены так же, как в Проводнике (числа в именах сравниваются как числа); в меню «Вид» → «Сортировка» вместо этого выбирается порядок по дате изменения или по размеру, по возрастанию или по убыванию.
- Галерея показывает дерево папок и изображения папки в виде миниатюр (см. [Галерея](#галерея)).
- Изображения из любых папок отмечаются как избранные клавишей `S`, после чего их можно просматривать и копировать вместе (см. [Избранное](#избранное)).
- Уменьшенные изображения сглаживаются mip-картами; масштаб 100% показывает один пиксель изображения на одном пикселе экрана при любом масштабе интерфейса Windows.
- Учитывается ориентация фотографий из EXIF.
- В строке состояния отображаются позиция в папке, имя файла, размер, разрешение, глубина цвета, формат, дата изменения и масштаб.
- Удаление перемещает файл в корзину после подтверждения.
- Изображения поворачиваются, отражаются и обрезаются с сохранением поверх файла или в другой файл; JPEG, который только повёрнут или отражён, сохраняет сжатые данные без изменений (см. [Поворот и обрезка](#поворот-и-обрезка)).
- Фон области изображения выбирается в меню «Вид» → «Фон»: тёмный (по умолчанию), чёрный, серый, белый или любой другой цвет. Прозрачные области изображения показываются на фоне шахматной доски, которая отключается в том же меню.
- Интерфейс отображается на русском языке, если Windows работает на русском, и на английском в остальных случаях; другой язык выбирается в окне «Справка» → «О программе».
- Программа не обращается к сети, кроме необязательной проверки обновлений (см. [Проверка обновлений и конфиденциальность](#проверка-обновлений-и-конфиденциальность)).

Поддерживаемые форматы: JPEG, PNG, GIF, WebP, BMP, TIFF, ICO, TGA, QOI, PNM (PBM, PGM, PPM, PAM), а также HEIC/HEIF, которые читаются поставляемыми с программой библиотеками [libheif](https://github.com/strukturag/libheif) и [libde265](https://github.com/strukturag/libde265), поэтому расширения из Microsoft Store для них не требуются. Кроме того, через Windows Imaging Component открываются все форматы, для которых в Windows есть кодек: AVIF (с расширением AV1 Video Extension из Microsoft Store), RAW-файлы фотоаппаратов, например CR2, CR3, NEF, ARW и DNG (с расширением Raw Image Extension, входящим в Windows 11), JPEG XR, DDS и форматы других установленных кодеков; им же передаются файлы HEIF, которые не удаётся прочитать libheif. Файлы AVIF показываются в списке всегда; если нужного расширения нет, в области изображения указывается, какое расширение требуется. Кодеки Windows также используются для файлов перечисленных выше форматов, которые не удаётся прочитать собственными декодерами qview. Анимированные GIF и WebP воспроизводятся при просмотре по кругу или столько раз, сколько указано в файле; галерея показывает их первый кадр, а строка состояния помечает их как анимацию.

## Установка

Установщик и переносной архив публикуются на странице [Releases](https://github.com/Fan4Metal/qview/releases).

Установщик `qview_<версия>_Setup.exe` не требует прав администратора: программа устанавливается в `%LOCALAPPDATA%\Programs\qview`. Параметр «Зарегистрировать qview для файлов изображений», включённый по умолчанию, регистрирует поддерживаемые типы файлов (см. [Сопоставление файлов](#сопоставление-файлов)); на последней странице установщик предлагает открыть параметры Windows, где qview выбирается программой по умолчанию. При удалении регистрация снимается.

Переносная версия `qview_<версия>_portable.zip` содержит программу в папке `qview` и работает без установки; при необходимости типы файлов регистрируются через «Файл» → «Сопоставление файлов…». В обоих случаях настройки хранятся в `%APPDATA%\qview`.

| Сохранение в другой файл или формат | `Ctrl+Shift+S` |
| Открытие в последнем выбранном редакторе | `Ctrl+E` |

| Переименование файла | `F2` (`Enter` переименовывает, `Esc` отменяет) |
| Отмена последнего переименования или сохранения (до 20 за сеанс) | `Ctrl+Z` |

Стрелки прокручивают изображение, если оно в этом направлении больше окна, а в остальных случаях переключают изображения. Буквенные клавиши работают и в русской раскладке.

## Поворот и обрезка

Поворот (`[`, `]`, панель инструментов, меню «Вид» и контекстное меню) и отражение (`H` — по горизонтали, `V` — по вертикали, меню «Вид» и контекстное меню) меняют только вид, пока не будут сохранены; строка состояния при этом указывает угол или отражение. «Файл» → «Сохранить» (`Ctrl+S`) записывает повёрнутое или отражённое изображение поверх файла, «Файл» → «Сохранить как…» (`Ctrl+Shift+S`) — в другой файл, формат которого определяется расширением: JPEG, PNG, WebP (без потерь), TIFF или BMP. В этом диалоге предлагается имя исходного файла с `_crop` для обрезанного изображения или `_rotate` для повёрнутого, `_flip` для только отражённого (`photo_crop.jpg`), с номером, если такой файл уже есть (`photo_crop_2.jpg`), поэтому ни один файл не заменяется случайно. Форматы, которые qview не записывает, например HEIC, AVIF, RAW и GIF, а также WebP со сжатием с потерями сохраняются через «Сохранить как», по умолчанию предлагается JPEG. Анимированные изображения не редактируются.

«Файл» → «Конвертировать в» (также в контекстном меню изображения и миниатюры в галерее) сохраняет копию изображения в формате JPEG, PNG, WebP (без потерь), TIFF или BMP рядом с исходным файлом, под тем же именем с новым расширением (`photo.heic` → `photo.jpg`, а если это имя занято — `photo_2.jpg`), без диалога; несохранённые поворот и отражение применяются к копии. Исходный файл не изменяется и остаётся текущим изображением; `Ctrl+Z` удаляет копию.

«Файл» → «Редактировать в» (также в контекстном меню изображения и миниатюры) перечисляет программы, которые Windows предлагает для этого типа файлов, как в списке «Открыть с помощью», включая приложения из Microsoft Store, например «Фотографии», а также пункт «Другая программа…» для любого исполняемого файла. Выбранная программа открывает изображение (в галерее — все выбранные изображения) и запоминается как редактор: «Файл» → «Открыть в <название>» (`Ctrl+E`) открывает её снова, в том числе после перезапуска. Пока редактор не выбран, `Ctrl+E` использует редактор, назначенный в Windows для этого типа (для большинства изображений — Paint). При открытии более пяти изображений сразу запрашивается подтверждение, так как программы, открывающие по одному файлу, откроют окно для каждого. Изображение, изменённое в редакторе, показывается заново после `F5`.

JPEG, который только повёрнут или отражён, не пересжимается: вместо этого меняется ориентация в EXIF (и в XMP, если она там есть), поэтому качество не теряется, а метаданные остаются прежними. Во всех остальных случаях изображение декодируется, отражается, поворачивается, обрезается и кодируется заново, JPEG — с качеством 92; профиль ICC и данные EXIF исходного файла переносятся, при этом ориентация сбрасывается, размеры обновляются, а встроенная миниатюра удаляется.

Обрезка (`C`, кнопка панели инструментов, меню «Вид» и контекстное меню) показывает рамку в середине изображения, отступающую от его краёв, и панель над ним. Рамка перемещается перетаскиванием изнутри и меняет размер за края и углы; перетаскивание за её пределами рисует новую рамку. На панели выбираются пропорции (свободные, исходные, 1:1, 4:3, 3:2, 16:9 и их книжные варианты), показывается размер рамки в пикселях и находятся кнопки «Сохранить» (`Enter`), «Сохранить как…» и «Отмена» (`Esc`). Во время обрезки переключение изображений и команды для файлов недоступны; поворот и отражение перемещают рамку вместе с изображением, а клавиши масштаба и `Ctrl+колесо` работают как обычно.

Файл никогда не перезаписывается на месте: новое изображение записывается во временный файл рядом с ним, который затем заменяет исходный с сохранением даты создания и прав доступа. Прежнее содержимое хранится в памяти до закрытия программы, поэтому `Ctrl+Z` («Файл» → «Отменить сохранение») восстанавливает его вместе с датой изменения; файл, созданный через «Сохранить как», при этом удаляется.

## Галерея

![Галерея: слева дерево папок, справа миниатюры изображений папки](images/gallery.png)

*Снимок экрана версии 0.2.0.*

Галерея открывается клавишами `G`, `Enter` и `Esc`, двойным щелчком по изображению или кнопкой на панели инструментов и показывает папку текущего изображения, всегда с меню и панелями (при открытии из полноэкранного режима этот режим снимается): слева дерево папок, справа изображения в виде сетки миниатюр под строкой с путём к папке и ползунком размера миниатюр. В дереве перечислены папки «Изображения» и «Рабочий стол» и диски; папка открывается щелчком, а раскрывается щелчком по стрелке или двойным щелчком. При установленном флажке «Вложенные папки» над сеткой изображения папки и всех её вложенных папок, кроме скрытых, показываются единым списком в выбранном порядке сортировки. Папки, выбранные в дереве, показываются так же, пока флажок не снят; при открытии файла показывается только его папка. В этом режиме строка состояния и всплывающая подсказка миниатюры показывают путь к изображению относительно папки, а флажок «По папкам» рядом с флажком «Вложенные папки», в остальное время неактивный, начинает действовать: при нём изображения показываются по папкам в порядке дерева (изображения папки перед изображениями её вложенных папок), сортируются внутри каждой папки, и каждая папка начинается с новой строки сетки под заголовком с путём к ней, числом изображений в ней и горизонтальной линией. Выбор «По папкам» сохраняется между запусками.

Показанные папки — выбранные в дереве, открытые по заголовку, достигнутые кнопкой «Вверх», а также папки открытых файлов — образуют историю, как в Проводнике: кнопки «Назад» и «Вперёд» панели инструментов, `Alt+←` (а также `Backspace`) / `Alt+→` и боковые кнопки мыши возвращают к предыдущей и следующей папке с выбранным в ней изображением, в прежнем виде (с вложенными папками или без них) и с прежней прокруткой. Кнопка «Вверх» и `Alt+↑` показывают папку уровнем выше; если показаны вложенные папки, выбранное изображение остаётся выбранным. История хранится до закрытия программы. В галерее эти три кнопки находятся на панели инструментов между кнопкой галереи и кнопкой удаления вместо кнопок просмотра, поворота и масштаба.

| Действие | Клавиши и мышь |
|---|---|
| Выбор изображения | щелчок, стрелки, `Page Up` / `Page Down`, `Home` / `End` |
| Показ выбранного изображения | `Enter`, `G`, двойной щелчок по миниатюре |
| Показ выбранного изображения в полноэкранном режиме | `F` |
| Полноэкранный режим галереи (с меню и панелями) | `Ctrl+Shift+F` |
| Размер миниатюр | ползунок над сеткой, `+` / `-`, `Ctrl+колесо` |
| Показ также изображений вложенных папок | флажок «Вложенные папки» над сеткой |
| Переход во вложенную папку (при флажке «По папкам») | двойной щелчок по её заголовку |
| Переход к предыдущей / следующей показанной папке | `Alt+←`, `Backspace` / `Alt+→`, боковые кнопки мыши, кнопки «Назад» / «Вперёд» панели инструментов |
| Переход в папку уровнем выше | `Alt+↑`, кнопка «Вверх» панели инструментов |
| Перечитывание папки, миниатюр и дерева папок | `F5` |
| Закрытие программы | `Esc` |

Выбранная миниатюра является текущим изображением: удаление, переименование, копирование и показ в Проводнике относятся к нему, в том числе из контекстного меню миниатюры. В этом меню, как и в меню пустого места сетки, также выбирается порядок сортировки. Миниатюры берутся из кэша миниатюр Windows, который заполняет и Проводник, поэтому уже просмотренная папка отображается сразу; для форматов, миниатюр которых Windows не создаёт, qview создаёт их сам. Изображение под указателем и выбранное изображение декодируются заранее, поэтому двойной щелчок показывает изображение без задержки. Список над сеткой задаёт пропорции ячеек: 1:1, 4:3, 3:2, 16:9, книжные 3:4, 2:3, 9:16 или «Авто», при котором берутся пропорции большинства изображений папки (они читаются из заголовков файлов при открытии папки, в большой папке — у 200 из них); ползунок задаёт их длинную сторону. Флажок «Заполнять ячейки» заставляет миниатюры заполнять ячейки с обрезкой краёв изображений; без него изображение показывается целиком. Размер миниатюр, эти настройки и ширина дерева сохраняются между запусками.

Несколько изображений выбираются как в Проводнике: `Ctrl`+щелчок добавляет изображение к выбранным или убирает его, `Shift`+щелчок выбирает изображения от последнего щёлкнутого до этого (`Ctrl+Shift`+щелчок добавляет их), `Shift` со стрелками, `Page Up`/`Page Down`, `Home` и `End` выбирает изображения по пути, `Ctrl+A` выбирает все, а рамка, которую тянут мышью с миниатюры или с промежутка между ними, выбирает задетые ею миниатюры (с `Ctrl` — в дополнение к уже выбранным); у верхнего и нижнего края сетки она прокручивает её. Щелчок по пустому месту, `Esc` или перемещение без `Shift` снимают выбор. Копирование, удаление (после одного подтверждения), переименование, «Конвертировать в» и добавление в избранное применяются ко всем выбранным изображениям — с клавиатуры, из меню и из контекстного меню выбранной миниатюры; выбранные миниатюры обведены синим и отмечены галочкой в углу, у остальных во время выбора показан пустой кружок (щелчок по кружку добавляет изображение к выбранным или убирает его, как `Ctrl`+щелчок в любом месте миниатюры), а строка состояния показывает, сколько изображений выбрано. При переименовании нескольких изображений запрашиваются имя и начальный номер, и каждое изображение получает это имя с номером в порядке сетки, с сохранением расширения (`отпуск_01.jpg`, `отпуск_02.heic`…); диалог показывает первые и последнее новые имена. Переименовываются либо все файлы, либо ни один, а `Ctrl+Z` возвращает прежние имена всем сразу. При конвертации нескольких изображений копии создаются по очереди, ход отображается в строке состояния; `Ctrl+Z` удаляет все копии.

## Избранное

Клавиша `S`, кнопка со звездой на панели инструментов, меню «Избранное» и контекстные меню изображения и миниатюры добавляют текущее изображение в избранное или убирают его оттуда. Избранное изображение отмечается звездой в углу миниатюры, на кнопке панели инструментов и в строке состояния. Пункт «Избранное» вверху дерева папок (а также «Избранное» → «Показать избранное») показывает в галерее избранные изображения из всех папок как одну папку, рядом с ним указывается их число: в порядке добавления или в другом порядке, выбранном в меню «Вид» → «Сортировка», который для избранного хранится отдельно от порядка папок (для него там есть пункт «По дате добавления»), или, при флажке «По папкам», по папкам под заголовками с полным путём к каждой папке; двойной щелчок по заголовку открывает эту папку. Пункт «Перейти к папке» (в меню «Избранное» и в контекстных меню) показывает папку выбранного изображения, и оно остаётся выбранным; кнопка «Назад» возвращает к избранному. Так же он работает для изображения, показанного вместе с вложенными папками. При просмотре изображения листаются в том же порядке. Изображение, убранное из избранного во время его показа, сразу исчезает из списка, и выбирается следующее.

Меню «Избранное», а при показе избранного и контекстные меню сетки копируют всё избранное сразу: «Копировать все» помещает файлы в буфер обмена для вставки в Проводнике, «Копировать все в папку…» копирует их в выбранную папку с окном хода копирования Windows и её вопросом о файлах с одинаковыми именами. «Очистить избранное…» после подтверждения убирает из избранного все изображения. Сами файлы при этом никогда не изменяются.

Избранное хранится в файле `favorites.txt` рядом с настройками (`%APPDATA%\qview\data`) и сохраняется после каждого изменения: это текстовый файл в кодировке UTF-8, по одному полному пути на строку в порядке добавления, который могут читать и другие программы и сценарии. Переименование и удаление файла в qview обновляют список. Избранный файл, которого больше нет в его папке (удалён, переименован или перемещён в другой программе), убирается из списка при показе избранного, о чём сообщает строка состояния; файлы папок, к которым нет доступа, например на отключённом диске, остаются в избранном.

## Проверка обновлений и конфиденциальность

Проверка обновлений необязательна и по умолчанию выключена. Если в окне «Справка» → «О программе» включён флажок **Проверять обновления при запуске (раз в сутки)**, программа не чаще раза в сутки запрашивает у GitHub Releases API (`api.github.com`) последний выпуск; кнопка **Проверить сейчас** в том же окне запрашивает его сразу. Запрос не содержит ничего, кроме версии программы в заголовке `User-Agent`, и ничего не скачивается и не устанавливается: если есть более новый выпуск, справа на панели инструментов появляется кнопка с его версией, которая открывает страницу выпуска в браузере. В остальном программа к сети не обращается.

## Использование

```
qview.exe [ФАЙЛ | ПАПКА]
```

Файл открывается вместе с остальными изображениями его папки; папка открывается в галерее.

Одновременно открыто только одно окно qview: если qview уже запущен, файл, открытый позднее (из Проводника или командной строки), отображается в существующем окне, которое переводится на передний план. Копии qview, запущенные из разных папок, работают независимо.

## Сопоставление файлов

Пункт меню «Файл» → «Сопоставление файлов…» регистрирует qview в Windows для текущего пользователя (права администратора не требуются; регистрируются в том числе HEIC/HEIF, AVIF, RAW и JPEG XR): каждый поддерживаемый формат получает собственный тип файла со значком, а qview появляется в списке «Открыть с помощью» и в разделе «Параметры» → «Приложения по умолчанию». Каждый значок представляет собой страницу с полосой цвета формата, на которой указано расширение.

<p align="center">
  <img src="images/file_types.png" width="520" alt="Значки типов файлов: JPG, PNG, GIF, BMP, TIF, WEBP, ICO, TGA, QOI, PNM, HEIC, AVIF, RAW и JXR">
</p>

Программу по умолчанию Windows разрешает выбирать только пользователю, поэтому регистрация предлагает qview, но не назначает его сама; программой по умолчанию qview становится только для расширений, которые не обрабатывает ни одна другая программа (например, QOI). Файлы, которые открывались в qview через «Открыть с помощью» ещё до регистрации, также получают значок и название своего типа. Кнопка «Выбрать по умолчанию…» открывает параметры Windows, где qview выбирается в разделе «Задать значения по умолчанию по приложению»; кроме того, Windows сама предлагает qview при следующем открытии изображения. В окне показано, какие типы qview открывает по умолчанию, а кнопка «Удалить регистрацию» удаляет всё, что было записано при регистрации. То же выполняется из командной строки, например установщиком:

```
qview.exe --register
qview.exe --unregister
```

Регистрация ссылается на расположение `qview.exe`; после перемещения программы регистрация выполняется повторно.

Режим масштаба, выбранный клавишами `1`–`4`, действует и для следующих изображений, в том числе после пошагового изменения масштаба. Клавиша `L` («Вид» → «Сохранять масштаб и положение») вместо этого сохраняет для следующих изображений масштаб, установленный пошагово, и положение прокрутки, что позволяет сравнивать серию снимков в одном и том же месте и масштабе; в строке состояния масштаб помечается как сохраняемый. Этот выбор между запусками не сохраняется. Положение и размер окна, видимость панели инструментов и строки состояния, цвет фона и шахматная доска, режим масштаба, порядок сортировки, язык, размер миниатюр галереи, пропорции ячеек, выбор «Заполнять ячейки» и «По папкам», ширина дерева папок, последний выбранный редактор и настройка проверки обновлений хранятся в `%APPDATA%\qview\data\app.ron`; избранное хранится отдельно, в `%APPDATA%\qview\data\favorites.txt`.

## Сборка

Требования: Windows 10 или новее, стабильный Rust с набором инструментов MSVC, Visual Studio 2022 Build Tools и [uv](https://docs.astral.sh/uv/).

```
uv run build.py          # target\release\qview.exe
cargo test
```

`build.py` сначала закрывает `qview.exe`, запущенный из папки `target` проекта (иначе файл заблокирован), а затем выполняет `cargo build --release`; дополнительные аргументы передаются cargo. Единственную зависимость скрипта, `psutil`, устанавливает uv. Если qview не запущен, подходит и обычный `cargo build --release`.

Окно отрисовывается egui/eframe через OpenGL (glow), изображения декодируются крейтом `image`. HEIC/HEIF декодируются библиотекой libheif с libde265, которые загружаются во время работы из файлов `heif.dll` и `libde265.dll`, расположенных рядом с `qview.exe`; при их отсутствии такие файлы передаются кодекам Windows. Обе библиотеки собирает скрипт `tools/build_heif.py` (требуются git и CMake из Visual Studio Build Tools) в папку `target\heif\bin` в указанных в скрипте версиях и со встроенной библиотекой времени выполнения C, поэтому Visual C++ Redistributable для них не нужен; `build.py` запускает его при первой сборке и копирует библиотеки к исполняемому файлу. Переменная окружения `QVIEW_TRACE=1` включает вывод времени запуска и декодирования в stderr.

## Установщик и выпуск

Скрипт выпуска собирает исполняемый файл, установщик и переносной архив (требуется Inno Setup 6):

```
python tools/make_release.py              # тесты, сборка, установщик, архив
python tools/make_release.py --no-tests   # то же без cargo test
python tools/make_release.py --install    # затем тихая установка поверх установленной копии
```

Файлы записываются в папку `dist`, версия берётся из `Cargo.toml`. Как и `build.py`, скрипт сначала закрывает `qview.exe`, запущенный из `target\release`. Установщик и архив содержат `heif.dll`, `libde265.dll` и папку `licenses` с текстами их лицензий и адресами исходного кода. Сценарий установщика находится в `tools/setup.iss`; значок установщика записывает команда `qview.exe --export-icon <файл.ico>`.

Выпуски на GitHub собирает workflow **Release** (`.github/workflows/release.yml`). После того как версия в `Cargo.toml` обновлена и закоммичена, отправка соответствующего тега публикует выпуск с установщиком и переносным архивом:

```
git tag v0.1.0
git push origin v0.1.0
```

Ручной запуск workflow (Actions → Release → Run workflow) только собирает файлы и прикрепляет их к запуску, не создавая выпуск.

## Используемые проекты

qview построен на следующих проектах с открытым исходным кодом:

- [egui / eframe](https://github.com/emilk/egui): интерфейс и окно программы;
- [image](https://github.com/image-rs/image): декодирование и кодирование большинства форматов;
- [libheif](https://github.com/strukturag/libheif) и [libde265](https://github.com/strukturag/libde265): декодирование HEIC/HEIF;
- [Inno Setup](https://jrsoftware.org/isinfo.php): установщик.
