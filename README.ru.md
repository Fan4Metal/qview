# qview

[English](README.md) | Русский

qview — быстрый и простой просмотрщик изображений для Windows. Изображение открывается за доли секунды, остальные изображения папки листаются без задержек, а окна настроек нет: немногочисленные параметры находятся в меню.

## Возможности

- Запуск до появления изображения занимает около 0,2 с: декодирование начинается ещё до создания окна и выполняется в фоновых потоках.
- Мгновенное листание: соседние изображения декодируются заранее.
- Изображения упорядочены так же, как в Проводнике (числа в именах сравниваются как числа).
- Уменьшенные изображения сглаживаются mip-картами; масштаб 100% показывает один пиксель изображения на одном пикселе экрана при любом масштабе интерфейса Windows.
- Учитывается ориентация фотографий из EXIF.
- В строке состояния отображаются позиция в папке, имя файла, размер, разрешение, глубина цвета, формат, дата изменения и масштаб.
- Удаление перемещает файл в корзину после подтверждения.
- Фон области изображения выбирается в меню «Вид» → «Фон»: тёмный (по умолчанию), чёрный, серый, белый или любой другой цвет.
- Интерфейс отображается на русском языке, если Windows работает на русском, и на английском в остальных случаях.

Поддерживаемые форматы: JPEG, PNG, GIF (первый кадр), WebP, BMP, TIFF, ICO, TGA, QOI, PNM (PBM, PGM, PPM, PAM).

## Установка

Установщик и переносной архив публикуются на странице [Releases](https://github.com/Fan4Metal/qview/releases).

Установщик `qview_<версия>_Setup.exe` не требует прав администратора: программа устанавливается в `%LOCALAPPDATA%\Programs\qview`. Параметр «Зарегистрировать qview для файлов изображений», включённый по умолчанию, регистрирует поддерживаемые типы файлов (см. [Сопоставление файлов](#сопоставление-файлов)); на последней странице установщик предлагает открыть параметры Windows, где qview выбирается программой по умолчанию. При удалении регистрация снимается.

Переносная версия `qview_<версия>_portable.zip` содержит программу в папке `qview` и работает без установки; при необходимости типы файлов регистрируются через «Файл» → «Сопоставление файлов…». В обоих случаях настройки хранятся в `%APPDATA%\qview`.

## Управление

| Действие | Клавиши и мышь |
|---|---|
| Следующее изображение | `→`, `Page Down`, `Space`, `Ctrl+→`, колесо вниз |
| Предыдущее изображение | `←`, `Page Up`, `Backspace`, `Ctrl+←`, колесо вверх |
| Первое / последнее изображение | `Home` / `End` |
| Увеличение / уменьшение | `+`, `=`, `-`; `Ctrl+колесо` масштабирует относительно курсора |
| Вписать в окно (только уменьшение) | `2`, `*` на цифровом блоке |
| Реальный размер (100%) | `1`, `/` на цифровом блоке |
| Прокрутка увеличенного изображения | стрелки, перетаскивание левой кнопкой |
| Поворот влево / вправо (только при просмотре) | `[` / `]`, `Ctrl+Alt+←` / `Ctrl+Alt+→` |
| Полный экран | `F`, `Ctrl+Shift+F`, двойной щелчок, средняя кнопка |
| Выход из полного экрана / закрытие | `Esc`; `Ctrl+W` и `Alt+F4` закрывают программу |
| Перемещение в корзину | `Delete` (`Enter` подтверждает, `Esc` отменяет) |
| Копирование файла в буфер обмена | `Ctrl+C` |
| Открытие файла | `Ctrl+O` или перетаскивание файла в окно |
| Открытие в программе по умолчанию | `Shift+E` |
| Перечитывание изображения и папки | `F5` |
| Показ и скрытие панели инструментов / строки состояния | `T` / `B` |
| Список сочетаний клавиш | `F1` |

Стрелки прокручивают изображение, если оно в этом направлении больше окна, а в остальных случаях переключают изображения. Буквенные клавиши работают и в русской раскладке. Двойной щелчок включает полноэкранный режим.

## Использование

```
qview.exe [ФАЙЛ | ПАПКА]
```

Файл открывается вместе с остальными изображениями его папки; папка открывается на первом изображении.

## Сопоставление файлов

Пункт меню «Файл» → «Сопоставление файлов…» регистрирует qview в Windows для текущего пользователя (права администратора не требуются): каждый поддерживаемый формат получает собственный тип файла со значком, а qview появляется в списке «Открыть с помощью» и в разделе «Параметры» → «Приложения по умолчанию». Каждый значок представляет собой страницу с полосой цвета формата, на которой указано расширение.

Программу по умолчанию Windows разрешает выбирать только пользователю, поэтому регистрация предлагает qview, но не назначает его сама. Кнопка «Выбрать по умолчанию…» открывает параметры Windows, где qview выбирается в разделе «Задать значения по умолчанию по приложению»; кроме того, Windows сама предлагает qview при следующем открытии изображения. В окне показано, какие типы qview открывает по умолчанию, а кнопка «Удалить регистрацию» удаляет всё, что было записано при регистрации. То же выполняется из командной строки, например установщиком:

```
qview.exe --register
qview.exe --unregister
```

Регистрация ссылается на расположение `qview.exe`; после перемещения программы регистрация выполняется повторно.

Положение и размер окна, видимость панели инструментов и строки состояния, а также цвет фона хранятся в `%APPDATA%\qview\data\app.ron`.

## Сборка

Требования: Windows 10 или новее, стабильный Rust с набором инструментов MSVC, Visual Studio 2022 Build Tools и [uv](https://docs.astral.sh/uv/).

```
uv run build.py          # target\release\qview.exe
cargo test
```

`build.py` сначала закрывает `qview.exe`, запущенный из папки `target` проекта (иначе файл заблокирован), а затем выполняет `cargo build --release`; дополнительные аргументы передаются cargo. Единственную зависимость скрипта, `psutil`, устанавливает uv. Если qview не запущен, подходит и обычный `cargo build --release`.

Окно отрисовывается egui/eframe через OpenGL (glow), изображения декодируются крейтом `image`. Переменная окружения `QVIEW_TRACE=1` включает вывод времени запуска и декодирования в stderr.

## Установщик и выпуск

Скрипт выпуска собирает исполняемый файл, установщик и переносной архив (требуется Inno Setup 6):

```
python tools/make_release.py              # тесты, сборка, установщик, архив
python tools/make_release.py --no-tests   # то же без cargo test
```

Файлы записываются в папку `dist`, версия берётся из `Cargo.toml`. Как и `build.py`, скрипт сначала закрывает `qview.exe`, запущенный из `target\release`. Сценарий установщика находится в `tools/setup.iss`; значок установщика записывает команда `qview.exe --export-icon <файл.ico>`.

Выпуски на GitHub собирает workflow **Release** (`.github/workflows/release.yml`). После того как версия в `Cargo.toml` обновлена и закоммичена, отправка соответствующего тега публикует выпуск с установщиком и переносным архивом:

```
git tag v0.1.0
git push origin v0.1.0
```

Ручной запуск workflow (Actions → Release → Run workflow) только собирает файлы и прикрепляет их к запуску, не создавая выпуск.
